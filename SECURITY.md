# Security Policy

## Supported Versions

JUNO is currently under active development. Security fixes are applied to the latest release and the current development version.

| Version | Supported |
| ------- | --------- |
| Latest release | :white_check_mark: |
| Development (`main`) | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in JUNO, please report it privately.

**Please do not open a public GitHub issue for security vulnerabilities.**

### Private Reporting

If GitHub Private Vulnerability Reporting is enabled for this repository, please use it to submit your report.

If private reporting is unavailable, please contact the project maintainer privately through the contact information available on the repository or the maintainer's GitHub profile.

### What to Include

Please provide as much of the following information as possible:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version or component
- The potential security impact
- Relevant logs, screenshots, or proof-of-concept code
- Any suggested mitigation or fix, if available

Please avoid including real credentials, authentication tokens, personal information, or other sensitive data in your report.

## Response

Security reports will be reviewed and investigated as reasonably possible.

If a vulnerability is confirmed, the project will work toward an appropriate fix and security release.

If a report is determined not to be a security vulnerability, it may be closed or redirected to the appropriate issue tracker.

## Scope

Security issues may include, but are not limited to:

- Authentication or authorization vulnerabilities
- Exposure or improper handling of credentials, tokens, or sensitive data
- Insecure network communication
- API security issues
- Local data or file security issues
- Remote code execution
- Injection vulnerabilities
- Dependency vulnerabilities
- Privacy-related security issues

## Responsible Disclosure

Please allow reasonable time for a vulnerability to be investigated and addressed before publicly disclosing it.

Do not publicly disclose:

- Credentials or authentication tokens
- Private user data
- Sensitive API information
- Working exploits that could put users at risk

We appreciate responsible security research and reports that help make JUNO safer for everyone.

Thank you for helping improve JUNO's security.
